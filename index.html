Atlases sarakstu kārtotājs

Nofotografē visas lapas — preces sakārtosim pēc plaukta adreses.

1. Pievieno visas lapas

Fotografē lapu taisni, labā apgaismojumā un tā, lai redzama visa tabula. Pievieno arī pārējās lapas no šī atlases saraksta.

Meta AI nolasīšanas iestatījumi

Meta AI foto nosūta internetā apstrādei. Vispirms vajadzīgs Meta API un Cloudflare Worker savienojums; atslēgu ievadi tikai Worker iestatījumos.

Iestatījumi tiek glabāti šajā pārlūkā. Meta API atslēgu šeit neievadi.

2. Pārbaudi sakārtoto sarakstu

Pārbaudi nolasītos datus — foto teksts reizēm var tikt atpazīts nepareizi. Vari labot laukus telefonā.

Pievieno lapu fotoattēlus, lai sāktu.

Izmantojot Meta AI, fotoattēli tiek nosūtīti Meta API apstrādei. Izmantojot ierīces OCR, foto paliek ierīcē. Nolasītās rindas saglabājas šajā pārlūkā.
